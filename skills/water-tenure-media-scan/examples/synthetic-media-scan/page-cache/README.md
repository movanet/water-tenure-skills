# Page cache (synthetic)

**Synthetic example, not real data.** Plain-text captures of the invented articles cited by the
synthetic media scan, one file per source id, as `verify_figures.py --cache` expects them. In a real
scan these files are written by `verify_figures.py --fetch`, or saved by hand from a browser when an
article body loads by script. Keep a real page cache out of version control if the pages are under
copyright.
